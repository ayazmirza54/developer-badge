# Ayaz Developer Badge

A professional interactive developer ID badge built around Ayaz's profile photo, engineering stats, and Wipro affiliation.

## Stack

- React + Vite
- Three.js / React Three Fiber
- React Three Drei
- React Three Rapier
- Meshline

## Badge

The badge uses the supplied profile image on the card face and presents concise professional stats rather than a generic business-card layout.
